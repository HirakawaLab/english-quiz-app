# Study Quiz Studio — 英語・社会の学習アプリ

React + TypeScript + Vite を利用したローカルファーストの学習アプリです。

## 起動方法（Windows / VS Code）

1. Node.js 20 以降をインストールします。
2. このフォルダーを VS Code で開きます。
3. ターミナルで実行します。

   ```powershell
   npm install
   npm run dev
   ```

4. ターミナルに表示される URL（一般に `http://localhost:5173`）を開きます。

公開用のファイルは `npm run build` で `dist/` に作成できます。

## 教科

### 英語
- 初期収録26問：元の6問、2026年度15問、追加写真5問
- 1問ずつ4択解答、正誤判定、文法解説、日本語訳
- 前回間違えた問題の復習
- 写真からOCRで英文・選択肢を読み取り、確認・修正・正解登録
- 登録問題の一覧、削除、JSONバックアップ・復元

### 社会
- 独立した「社会」教科タブ
- オリエント：時代の流れ・重要事項・例題2（1問）
- 古代ギリシア：エーゲ文明・ポリス・民主政・戦争・文化、例題3・例題7（2問）
- 解説を読む／問題に挑戦、1問ずつ解答・正誤判定・解説
- 社会科独自の解答履歴、前回間違えた問題の復習
- 写真から読み取った内容を整理して表示。原資料の写真も折りたたみで確認可能

## データと注意事項

- ブラウザの `localStorage` に保存します。英語は `english-quiz-questions-v1` / `english-quiz-history-v1` を引き続き使用するので以前のデータを保持できます。
- 社会の解答履歴は `study-social-history-v1` に保存します。
- 英語の「問題一覧」からダウンロードするバックアップJSONに、存在する社会の履歴も含めます。復元時は `socialHistory` があるときだけ社会履歴も復元します。
- 画像はOCR時にブラウザ内で処理し、アップロード先のサーバーを用意していません。OCR用の言語データ読み込みにインターネット接続が必要です。
- 社会の解説は掲載写真を要約・整理した教材です。写真の文字・問題文は誤認識の可能性があるため、学習時は折りたたみの原資料写真と照合できます。
- 社会の問題の正解は、オリエント例題2＝④、古代ギリシア例題3＝③、ギリシア文化例題7＝③です。
- 英語の写真読み取りを社会科の写真に流用する機能はまだありません。社会科の項目は今回の3つを初期登録しています。

## 更新時の注意

新しい ZIP のフォルダーを展開して、ソースを置き換えたうえで `npm install`、`npm run dev` を行ってください。同じブラウザ・同じ URL で実行するとき、`localStorage` の以前の学習記録は維持されます。ただし、ブラウザのストレージを削除した場合や URL のオリジンを変更した場合は引き継がれないため、事前にバックアップをお勧めします。
